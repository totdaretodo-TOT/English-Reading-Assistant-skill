# English Reading Assistant Skill

`english-reading-assistant` 是一个用于把英文文章转换成单文件沉浸式双语阅读 Web App 的  Skill。它面向英语学习场景，会把原始英文文本加工成带有词汇高亮、逐段中译、阅读进度、字体调节和暗色模式的 `index.html` 页面。可以导入复制好的文字，图片，world，pdf，因为丰富度的原因，导入word和pdf所需时间较长。


## 适用场景

当用户希望把一篇英文文章、短文、演讲稿、新闻摘录或学习材料变成可交互的英语阅读页面时，可以使用这个 Skill。

适合的请求示例：

```text
把这篇英文文章做成双语沉浸阅读网页
```

```text
用 english-reading-assistant 生成一个可直接打开的 index.html
```

```text
请把下面这段英文做成带生词本和点击翻译的阅读页面
```

## 输入

用户提供一篇英文文章或一段英文文本。文本可以很短，也可以是较长文章。

Skill 会根据文章长度自动调整核心生词数量：

- 短文，小于 300 词：提取 5-8 个核心生词
- 中等文章，300-800 词：提取 8-15 个核心生词
- 长文，大于 800 词：提取 15-25 个核心生词

## 输出

输出为一个完整可运行的 `index.html` 文件，包含：

- HTML 结构
- 内嵌 CSS
- 内嵌 JavaScript
- 文章正文
- 中英双语翻译
- 内置词典数据
- 响应式交互逻辑

生成结果应无需构建工具，直接用浏览器打开即可预览。

## 核心功能

生成的阅读页面应包含以下能力：

- 经典书籍风格排版
- 护眼纸张色背景
- 首段首字母下沉
- 核心生词自动高亮
- 生词 Tooltip
- 点击任意英文单词查看音标和中文释义
- 点击英文段落展开或折叠中文翻译
- 右侧固定生词本
- 移动端底部生词抽屉
- 顶部阅读进度条
- 字体大小 A- / A+ 调节
- 字号设置保存到 `localStorage`
- 日间 / 夜间模式切换
- 键盘可访问性支持
- 响应式桌面端和移动端布局

## 视觉规范

页面应体现经典读物的高级感，而不是普通博客或工具页。

推荐设计方向：

- 英文主体使用衬线字体：

```css
'Playfair Display', Georgia, 'Times New Roman', 'Noto Serif SC', 'SimSun', serif
```

- 中文翻译可使用宋体或楷体风格字体
- 日间背景使用柔和纸张色，例如 `#f4f1ea` 或 `#FAF9F6`
- 暗色模式使用深色背景和暖色文字
- 文本与背景对比度满足 WCAG AA，至少 4.5:1
- 交互元素应优雅、克制、适合长时间阅读

## 无障碍要求

生成页面需要关注基础无障碍体验：

- Tooltip 使用 `role="tooltip"`
- 被解释词汇使用 `aria-describedby`
- 可展开翻译区域维护 `aria-expanded`
- 高亮词汇支持 Tab 聚焦
- Enter 键可触发 Tooltip
- 所有正文文本保持足够颜色对比度

## 使用方式

把 `SKILL.md` 安装或放入 Codex 可识别的 skills 目录后，在对话中提供英文文本，并说明想生成沉浸式阅读页面即可。

示例：

```text
请使用 english-reading-assistant，把下面这篇文章生成一个完整的 index.html：

[在这里粘贴英文文章]
```

生成后应得到一个完整的单文件网页，可直接打开查看。

## 实现注意事项

- 不输出半成品代码或占位符
- 不依赖外部构建工具
- CSS 写在 `<head>` 的 `<style>` 中
- JavaScript 写在 `</body>` 前的 `<script>` 中
- JavaScript 使用 `'use strict'`
- 使用语义化 HTML5 标签
- 尽量保证离线可阅读，Google Fonts 失效时也不能影响主要排版
- 桌面端和移动端需要分别优化交互布局
